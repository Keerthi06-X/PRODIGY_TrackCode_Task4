### Objective
Analyze and visualize sentiment patterns in social media data to understand public opinion towards brands and topics.

### Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

### Tasks Performed
- Data Cleaning
- Sentiment Analysis
- Bar Chart Visualization
- Pie Chart Visualization
- Brand-wise Analysis

### Outcome
Identified positive, negative, and neutral sentiment trends from social media conversations.
